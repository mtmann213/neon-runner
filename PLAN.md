# Development Roadmap: Neon Runner

## Phase 4: World Building & Biomes
- [ ] **Lava Biome:** Implement a fire level with rising lava mechanics.
- [ ] **Moving Platforms:** Add oscillating and path-based platforms.
- [ ] **Dynamic Weather:** Randomly trigger screen-space effects like "Neon Rain" or "Cyber Dust."

## Phase 5: Advanced AI & Combat
- [ ] **Pathfinding:** Implement simple A* or waypoint-based navigation for smarter enemies.
- [ ] **Enemy States:** Transition enemies between Idle, Patrol, and Alert/Attack modes.
- [ ] **Weapon Variety:** Add new projectile types like laser beams or wave shots.

## Phase 6: Metaprogression & Economy
- [ ] **Currency System:** Collect "Neon Shards" during runs.
- [ ] **Upgrade Shop:** Spend shards on permanent upgrades (e.g., higher health, faster fireball cooldown).
- [ ] **Achievements:** Reward players for specific feats (e.g., "Defeated Boss without taking damage").

## Phase 7: Technical Polish
- [ ] **Sprite Support:** Migrate from procedural primitives to high-quality sprite sheets.
- [ ] **Ghost Trail:** Add a multi-frame "afterimage" trail when moving at high speeds.
- [ ] **ECS Architecture:** Move to a true Entity Component System for more efficient entity management.
- [ ] **Sound Overhaul:** Add specific sound effects for every power-up and enemy death.
